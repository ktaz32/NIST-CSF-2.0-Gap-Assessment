# Organization Profile — Northstar HealthTech

## Organization Overview

Northstar HealthTech is a fictional mid-sized healthcare technology company used solely for this cybersecurity assessment portfolio project.

The organization provides cloud-hosted healthcare workflow and analytics services to healthcare-sector customers.

This environment has been intentionally designed to contain realistic cybersecurity strengths and control gaps so that a structured NIST Cybersecurity Framework 2.0 assessment can be performed.

---

## Organization Size

- Approximately 250 employees
- Hybrid workforce
- Corporate headquarters and remote employees
- Small internal IT and cybersecurity team
- Cloud-first technology strategy

---

## Technology Environment

Northstar HealthTech uses:

- Microsoft 365
- Microsoft Entra ID
- Windows 11 endpoints
- AWS cloud infrastructure
- GitHub
- SaaS business applications
- VPN-based remote access
- Microsoft Defender endpoint protection
- Centralized security logging
- Third-party technology vendors

---

## Cloud Environment

AWS services include:

- IAM
- S3
- EC2
- CloudTrail
- Security Groups

The environment contains several intentionally modeled control weaknesses, including excessive IAM permissions and incomplete logging coverage.

---

## Identity and Access Management

Identity services include Microsoft Entra ID and AWS IAM.

Current-state characteristics include:

- MFA implemented for selected accounts
- Administrative accounts with elevated privileges
- Inconsistent privileged-access review
- Some excessive or stale cloud permissions
- No fully mature privileged access management program

---

## Endpoint Security

Corporate Windows endpoints use Microsoft Defender.

Security capabilities include:

- antivirus
- endpoint monitoring
- operating-system security controls
- centralized authentication logging

Control maturity varies across the environment.

---

## Security Monitoring

Security telemetry includes:

- Windows Security logs
- endpoint events
- AWS CloudTrail
- authentication events
- selected cloud security events

The organization has basic monitoring capability but does not yet have complete visibility across all high-value activity.

---

## Incident Response

Northstar HealthTech has informal incident-handling procedures.

Current limitations include:

- incomplete formal playbooks
- inconsistent incident classification
- limited tabletop exercise history
- incomplete lessons-learned processes

---

## Vulnerability Management

Vulnerability identification occurs periodically.

However:

- remediation SLAs are not formally defined
- prioritization is inconsistent
- risk acceptance procedures are immature
- reporting metrics are limited

---

## Third-Party Risk

The organization depends on multiple SaaS and technology vendors.

Third-party security reviews occur inconsistently and are not governed by a mature vendor-risk management process.

---

## Business Priorities

Northstar HealthTech prioritizes:

1. Protection of healthcare-related information
2. Availability of customer-facing services
3. Protection of employee and customer identities
4. Secure cloud operations
5. Regulatory and contractual compliance
6. Resilience against cyber incidents

---

## Assessment Purpose

The purpose of this project is to evaluate Northstar HealthTech's cybersecurity posture using NIST Cybersecurity Framework 2.0 and to produce:

- an evidence-based maturity assessment
- prioritized cybersecurity gaps
- a business-oriented risk register
- remediation recommendations
- an executive maturity dashboard
- a phased improvement roadmap

---
